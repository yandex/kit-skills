# Presets

Generated by `scripts/design.py presets list --markdown`; do not edit by hand.
A preset is a partial `settings` object with real key names; read one with
`design.py presets show <Widget> <preset>` and merge it with `presets apply`.
An *optional idea* rests on fewer than 3 stores of the sample: use it when the user asks for that look, never as a default.
A widget marked *leave default* has no preset: the sample shows nothing worth changing.
