# running-line — превью

Горизонтальная лента во всю ширину: ДВА ряда бегущих фраз высотой 48px каждый — верхний контурный (цвет фона + обводка text-shadow), нижний сплошной. Опция isBlurry размывает края градиентом.

**Честное ограничение (светлая тема по умолчанию):** контурный ряд на светлом фоне почти не виден (цвет = фон страницы), а 48px обоих рядов перекрикивают заголовки соседних секций. Паттерн рассчитан на ТЁМНУЮ или акцентную палитру и на роль громкого промо-акцента; как «тонкий разделитель» на светлой теме НЕ работает — не ставить рядом с hero. Разметка и css — официального примера доки, внутренности намеренно не правлены.
