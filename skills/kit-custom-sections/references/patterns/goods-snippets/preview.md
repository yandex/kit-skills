# goods-snippets — превью

Полка товаров из категории или подборки (featured-products-controller, карточка — product-snippet-controller). Сверху заголовок секции; если источник — категория или подборка с заданным slug, заголовок ведёт на её страницу, а под полкой стоит кнопка outlined с текстом showAllText (по умолчанию «Смотреть все»; по центру, на телефоне на всю ширину). Источник без товаров — секция не рисуется (остаётся только ритм-отступ обёртки); пока товары грузятся — count скелетонов карточек в той же раскладке.

**Компьютер (от 768px).** layout grid и grid-strip — сетка из columns колонок (2–6), промежутки hGap/vGap из spacing-токенов (по умолчанию 24/48px); на 768–1199px 5–6 колонок ужимаются до 4, на 768–1023px 4–6 — до 3. layout carousel — платформенная карусель: columns слайдов, стрелки по краям, прокрутка с привязкой (на планшете колонки карусели не ужимаются).

**Телефон (до 768px).** grid — сетка ровно в 2 колонки, промежуток не больше 16px, между рядами не больше 40px; видно не больше maxRowsTouch рядов (по умолчанию 2 ряда = 4 товара), остальные скрыты CSS (DOM тот же) — к ним ведёт кнопка под полкой, если она есть; одинокая карточка в последнем ряду скрывается. grid-strip (по умолчанию) — горизонтальная лента с привязкой к карточке, выходит к краям экрана: 2 карточки (columnsTouch 2) или 1 (columnsTouch 1) и край следующей примерно на 48px. carousel — та же платформенная карусель со свайпом без стрелок: columnsTouch слайдов и край следующего (48px минус промежуток). По замерам витрин ряд сетки из 2 карточек занимает около 0,6 экрана телефона, лента — около 0,7 экрана при любом count: поэтому по умолчанию лента, а сетка ограничена 2 рядами.

**Карточка.** Фото — первое фото товара (видео пропускается) в пропорции, вписывании, затемнении и фоне из темы магазина (globals.productSnippet.photo; фон вне none/primary/secondary/neutral сводится к none), скругление из темы, alt — название товара. На фото слева сверху метки товара (текст метки на плашке цвета фона страницы), справа сверху круглая кнопка избранного на полупрозрачной подложке цвета фона (контур сердца; у добавленного — залитое сердце брендового цвета; подпись для скринридера). Ниже цена md semibold (скидка — как в теме или по card.discount) и название sm в titleLines строк; порядок «цена — название» берётся из темы. Дальше по флагам бейджи Сплита и скидки Пэй (платформа рисует их, только если у магазина они включены), внизу кнопка корзины на всю ширину карточки, которая превращается в степпер. card.cartButton default — кнопка есть, только если тема не выключила её для полок; цвет secondary или primary тоже из темы. На телефоне кнопка корзины по умолчанию скрыта (card.hideCartButtonTouch). Товар не в наличии — фото приглушено, неактивная кнопка с outOfStockText (пустая строка — без кнопки). Наведение только на устройствах с курсором: фото плавно увеличивается на 4%, название окрашивается брендовым цветом; при reduced motion — без анимации.

Цвета — только токены темы.

**Переезд с v2.** Витрина подставляет ключам, которых нет в настройках, умолчания схемы v3 (по коду платформы с 26.10.2026), поэтому настройки v2 без новых ключей рисуются не как v2: на телефоне лента вместо сетки (layout grid-strip; в сетке — не больше 2 рядов, maxRowsTouch), на фото кнопка избранного (card.showFavourite), под полкой из категории или подборки кнопка «Смотреть все» (showAllText), кнопка корзины на телефоне скрыта (card.hideCartButtonTouch). Вид v2 возвращают явные значения в settings при переезде: layout grid, card.showFavourite false, showAllText пустая строка, card.hideCartButtonTouch false, maxRowsTouch 3 — сетки без потолка рядов в v3 нет. Отличия от v2 и при этих значениях: оформление карточки (цена md вместо 2xl, метка на плашке цвета фона вместо чёрной, увеличение фото 4% вместо 15%), кнопка корзины следует теме, фото — в пропорции темы (в v2 всегда 1:1), одинокая карточка в последнем ряду на телефоне скрыта.

**Переезд с v3.** Разметка и стили прежние, изменилась схема. Ритм verticalRhythm/verticalRhythmTouch по умолчанию 0 (был 500/300): новая секция стоит на отступах секции, как нативные соседи; перенесённая сохраняет свои явные значения ритма. Умолчание заголовка titleText (было «Популярное») в схеме пустое: ключ, которого нет в settings, витрина рисует пустым, а не текстом каталога.
