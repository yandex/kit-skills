# logo-wall — превью

Блок доверия: логотипы партнёров, клиентов, брендов в ассортименте или изданий, которые о магазине писали. Над блоком необязательный заголовок секции 24px (`ya-kit-section-title`: h2, первый заголовок секции на странице витрина делает h1), явного h1 в паттерне нет. Две раскладки (`layout`).

**Сетка (`grid`, по умолчанию).** Ряды равных ячеек, промежуток 24px, неполный последний ряд стоит по центру. Колонок `columns` 3–6 (по умолчанию 5), от 768 до 1199px не больше 4, до 767px — `columnsTouch` (2 или 3), промежуток 16px. Логотип вписан (`fit=contain`) в рамку 5:2 высотой `logoHeight` (по умолчанию 64px, рамка 160×64); в узкой ячейке рамка сжимается по ширине ячейки. На контейнере 1200px при 5 колонках ячейка около 220px, логотип 160×64. На телефоне рамка ×0.75: при ширине 390px, полях 16px и 2 колонках ячейка около 170px, логотип 120×48; при 3 колонках рамка около 92×37, поэтому 3 колонки — только для компактных знаков. Подпись `caption` — текст sm вторичным цветом под логотипом, по центру, строка до 36 знаков. С `link` вся плитка — ссылка `ya-kit-link`: адрес другого домена атом открывает в новой вкладке с `rel="noopener noreferrer"`, страницу витрины — в той же (по коду атома, см. pitfalls.md); внешний адрес пишется полностью, с `https://`, иначе атом примет его за путь внутри витрины. При наведении мышью плитка приподнимается на 2px, фокус с клавиатуры обводится цветом бренда. Имя ссылки для незрячих — `name` скрытым текстом.

**Бегущая строка (`marquee`).** Один ряд плиток постоянной ширины (рамка 160×64, на телефоне 120×48) с промежутком 48px, на телефоне 32px. Две одинаковые группы, трек уезжает на половину своей длины; группа не уже полосы, поэтому стык не виден и при 3–4 логотипах (тогда они расходятся шире). Круг длится 8s + N × шаг (шаг: медленно 5s, обычно 3.5s, быстро 2.2s; 8 логотипов при обычной скорости — 36s). Пауза при наведении мышью (`pauseOnHover`), края растворяются маской на 8% ширины (`fadeEdges`). Ссылок и подписей в строке нет: движущаяся ссылка — плохая цель для клика; `name` уходит в alt. Копия группы скрыта от экранных дикторов. При системной настройке «уменьшить движение» анимация выключается, копия прячется, логотипы переносятся в неподвижные ряды по центру. Полоса стоит внутри полей секции; от края до края — `section.hPaddingDesktop`/`hPaddingMobile` = "0" (заголовок тогда тоже прижмётся к краю).

**Общее.** `tileBackground: neutral` — плитка на нейтральном фоне темы (`--ys-background-neutral`) со скруглением темы (skinRounded 150), отступ 24/20px, на телефоне 16/12px, промежуток строки 24px (на телефоне 16px); годится только для логотипов с прозрачным фоном: белый прямоугольник JPG на плитке виден. `grayscale` — логотипы серые с прозрачностью 70%, цвет возвращается при наведении мышью и фокусе, на телефоне остаются серыми. Пока логотип не загружен, на его месте `name` полужирным текстом lg в той же рамке. Файл логотипа обрезать по краям знака: пустые поля в файле уменьшают знак внутри рамки. Цвета только токены темы, палитра секции слушается смены темы.

**Когда натив.** Простую статичную стену логотипов проще собрать нативным FeaturedCollections через kit-storefront-constructor: соотношение 2:1, `imageFit` contain, без рамки и затемнения, 4–6 колонок, две колонки на телефоне, заголовки модулей выключены или служат подписями. Этот паттерн нужен, когда требуется бегущая строка, монохром с цветом при наведении, 3 колонки на телефоне или плитки без карточного оформления натива. Сертификаты и сканы документов (портрет 3:4) сюда не подходят: логотипы здесь вписываются в широкую рамку одной высоты.

**Не проверено.** Атрибута `alt` у `ya-kit-image` нет в таблице доки (в справочнике он помечен «(код)»); по коду витрины атом передаёт его в `<img>`, живьём не проверено. Выбор вкладки у `ya-kit-link` взят из кода атома (атрибут `target` в `tags.md` помечен «(код)»), на витрине живьём не проверен. Раскладка сверена на макете DOM атомов в браузере (2026-09-24, ширина 1440, 1024 и 390px, стык строки, режим «уменьшить движение»); рендер на витрине (L2) не проверялся.

**Переезд с v1.** Разметка и стили прежние, изменилась схема. Ритм verticalRhythm/verticalRhythmTouch по умолчанию 0 (был 500/300): новая секция стоит на отступах секции, как нативные соседи; перенесённая сохраняет свои явные значения ритма. Умолчание заголовка titleText (было «Партнёры») в схеме пустое: ключ, которого нет в settings, витрина рисует пустым, а не текстом каталога.
