# video-reels — превью

Карусель коротких роликов: видеоотзывы, распаковки, демонстрации «как пользоваться». Заголовок секции — 24px (`ya-kit-section-title`: h2, первый заголовок секции на странице витрина делает h1), необязателен. Карточка — рамка с роликом, скругление из темы (skinRounded 250), формат 9:16 (frameRatio: ещё 4:5 и 1:1); до первого кадра рамка залита `--ys-background-secondary`, кадр кадрируется fit=cover. Под рамкой — подпись md medium не длиннее двух строк и необязательная ссылка sm (например, на товар из ролика; видна, только если заданы и текст, и адрес). Сам ролик ссылкой не обёрнут: нажатие управляет плеером.

**Десктоп (1024+).** 4 ролика в ряду (columns 3–6), отступ 16px (hGap — токены карусели), стрелки по краям; на экранах уже 1450px платформа сама переносит их внутрь. На контейнере ~1150px карточка 9:16 — около 275×490px. **Планшет 768–1023.** Не больше трёх в ряд: стиль паттерна переопределяет число колонок карусели. **Телефон (до 767).** Стрелок нет, ролики листаются свайпом. Один в ряду (columnsTouch 1, по умолчанию): соседний выглядывает на треть ширины, на экране 390px карточка около 236×420px (у 4:5 и 1:1 выглядывает меньше, карточка около 280px шириной). Два в ряду: сетка примерно по 155px с краем следующего.

**Воспроизведение (playback).** `queue` (по умолчанию) — видимые ролики запускаются сами без звука и идут по очереди (`ya-kit-video-queue`): одновременно играет один, после конца — следующий видимый, ушедший из вида встаёт на паузу. Компактный скин плеера: кнопка звука в углу и тонкая полоса прогресса, нажатие ставит на паузу. `tap` — ролик стоит на первом кадре и запускается нажатием, со звуком: для отзывов, где важна речь. `background` — все видимые ролики крутятся по кругу без звука и без кнопок (`skin-variant="default"` + `is-skinless`): только короткие декоративные петли без речи.

Автолистание карусели (autoplay) по умолчанию выключено: включённое уводит ролик во время просмотра. Роликов до 12. Ролик без видео пропускается; пока видео нет ни у одного, секция не выводится (в превью конструктора тоже), на странице остаётся только вертикальный отступ ритма. Видео выбирает мерчант в форме секции — `new` печатает пустые заглушки `modules[].video`. Текст в сам ролик не вшивать: подпись — живой текст под роликом.

Одно широкое видео во всю ширину — не этот паттерн: нативный BannersCarousel с одним видео-слайдом и отдельным файлом для телефона (mediaMobile) кадрирует правильно, а здесь горизонтальный ролик в вертикальной рамке теряет две трети кадра.

**Переезд с v1.** Разметка и стили прежние, изменилась схема. Ритм verticalRhythm/verticalRhythmTouch по умолчанию 0 (был 500/300): новая секция стоит на отступах секции, как нативные соседи; перенесённая сохраняет свои явные значения ритма. Умолчание заголовка titleText (было «Видео покупателей») в схеме пустое: ключ, которого нет в settings, витрина рисует пустым, а не текстом каталога.
