# goods-filters — превью

Заголовок, ряд кнопок-вкладок (value-controller хранит выбранную), под ними карусель товаров активной вкладки. У каждой вкладки свой источник товаров (ProductsSource) — мерчант выбирает в форме; answers задают только названия вкладок. Токены темы.

**Переезд с v2.** Разметка и стили прежние, изменилась схема. Ритм verticalRhythm/verticalRhythmTouch по умолчанию 0 (был 500/300): новая секция стоит на отступах секции, как нативные соседи; перенесённая сохраняет свои явные значения ритма.
