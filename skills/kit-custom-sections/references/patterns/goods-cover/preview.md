# goods-cover — превью

Полка товаров с текстовой обложкой: заголовок, описание и кнопка рядом с каруселью товаров из категории или подборки (featured-products-controller). Для главной сначала нативная полка; этот блок — когда у полки нужен свой рассказ («Подборка недели», сезонная коллекция).

**Компьютер (от 768px).** Обложка 300px слева (`coverSide: right` — справа), полка — остальная ширина, 3 карточки в карусели, между колонками 48px; колонки выровнены по вертикали по центру. Заголовок — h2 размера заголовка темы (`globals.typography.titleSize`), semibold, цвет палитры, как заголовки секций; описание — markdown 16px основным цветом, не шире 36rem; кнопка — основная кнопка темы с подписью `cover.buttonText`.

**Телефон (до 767px).** Обложка над полкой, в карусели 2 карточки в ряду (`columnsTouch` 1 — одна крупная).

**Кнопка.** Видна, только когда заданы и ссылка `cover.url.link`, и подпись `cover.buttonText`: подпись говорит, куда ведёт кнопка («Все бестселлеры»), а не «Перейти». Ссылка без подписи — `new` отказывает. Без ссылки блок без кнопки.

**Товары.** `count` 3–8 (по умолчанию 6), источник — `source` (категория или подборка; без него секция пустая, `new` называет заглушку).

**Переезд с v2.** Заголовок стал h2 размера темы цветом палитры (был 3xl bold брендовым цветом и не заголовком); «Перейти» — теперь `cover.buttonText`, и без подписи кнопки нет — у перенесённой секции задать подпись, иначе кнопка пропадёт; на телефоне 2 карточки в ряду вместо одной (прежний вид — `columnsTouch` 1); в карусели 6 товаров вместо 5 (`count` 5 — как раньше).
