# cta-band — превью

Акцентная полоса призыва к действию во всю ширину контента. Ставится между смысловыми блоками главной как точка действия или последним блоком перед подвалом. Первый экран с h1 — это `hero`; кнопка без подложки, пристёгнутая к секции над ней, — `button-row`.

**`layout: split` (по умолчанию).** Одна строка: слева заголовок h2 и текст под ним, справа кнопка; обе части отцентрованы по вертикали, между ними не меньше 32px, текст не шире 44rem. Планшет (768–1023px): та же строка. Телефон (до 767px): столбик по левому краю — заголовок, текст, под ними кнопка шириной по тексту, до кнопки 24px.

**`layout: centered`.** Столбик по центру на всех ширинах: заголовок, текст и кнопка выровнены по центру, до кнопки 24px. Текстовый блок не шире 48rem, текст — 40rem.

**Подложка `surface`.** `secondary` (по умолчанию) — вторичный фон темы, `neutral` — нейтральный фон темы; углы скруглены по теме (skinRounded 200), боковые поля внутри 48px на десктопе, 40px на планшете, 24px на телефоне: при ширине 390px и полях секции 16px на текст остаётся 310px. `none` — без фона и без боковых полей: текст встаёт по краю контента соседних секций. Поле сверху и снизу внутри полосы — `innerPadding` (по умолчанию 500 = 40px, `0` — только для полосы без подложки); на телефоне оно не больше 32px.

**Заголовок и текст.** `titleSize: section` — размер заголовка темы (`globals.typography.titleSize`, 24–40px на компьютере), bold, как у заголовков секций; между заголовком и текстом 8px. `display` — шкала первого экрана: 52px на десктопе, 40px на планшете, 34px на телефоне, между заголовком и текстом 24px; уровень остаётся h2 — вровень с заголовками секций. Крупный заголовок — для одного главного призыва на странице. Текст — основным цветом, размер `textSize` md (по умолчанию), lg или xl. Строки заголовка выравниваются по длине, у текста нет висячего последнего слова (text-wrap balance и pretty; браузер без их поддержки переносит как обычно). Перенос строки из поля текста действует на всех ширинах, на телефоне длинная строка дополнительно переносится — ручной перенос ставить только между короткими фразами.

**Кнопка.** Кнопка платформы: `buttonColor` primary (по умолчанию), secondary, neutral, outlined или flat; `buttonSize` lg (по умолчанию), md или sm. Выводится только при непустых тексте и ссылке; `buttonUrl` в answers обязателен — ссылка на то, к чему зовёт текст кнопки.

**Длина текстов.** Заголовок до ~40 знаков: `section` на телефоне — до двух строк, `display` — до трёх. Текст — одна-две фразы, до ~140 знаков. Кнопка — 1–3 слова.

**Необязательные части.** Пустой заголовок, пустой текст и кнопка без ссылки не выводятся, пустых мест не остаётся; в `split` без заголовка и текста кнопка встаёт к левому краю, поэтому одиночную кнопку ставят в `centered`. Если в settings нет полей оформления (переезд живой секции на этот шаблон), действуют значения по умолчанию: split, вторичный фон, поле 40px, кнопка primary lg, заголовок размера темы, текст md.

Цвета — токены палитры и темы, hex нет; шрифт — шрифт темы.

**Пресеты answers** (тексты и ссылку подставить свои):
- центрированный призыв без подложки: `{"layout": "centered", "surface": "none", "titleSize": "display", "titleText": "…", "subtitleText": "…", "buttonText": "…", "buttonUrl": {"link": "…", "linkId": ""}}`;
- кнопка по центру на подложке, без заголовка и текста: `{"layout": "centered", "titleText": "", "subtitleText": "", "innerPadding": "400", "buttonText": "…", "buttonUrl": {"link": "…", "linkId": ""}}`.

**Переезд с v2.** Заголовок секции теперь h2, вровень с заголовками нативных секций (был h3); вид не меняется. Описания и лид — основным цветом текста (были вторичным, контраст 3,3–3,7:1); прежний приглушённый вид — descriptionTone: secondary.
