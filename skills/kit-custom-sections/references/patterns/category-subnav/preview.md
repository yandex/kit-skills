# category-subnav — превью

Навигационный ряд над листингом. Источник пунктов задаёт обязательный ответ `source`:

- `current` — подкатегории текущей категории (ya-kit-categories-controller; категория берётся по адресу страницы, на фасетной коллекции — по её категории). Первый пункт `view.allText` («Все») ведёт на родительскую категорию; пункт текущей страницы выводится текстом с aria-current, а не ссылкой. В категории без подкатегорий (`siblingsOnLeaf`, по умолчанию да) ряд показывает соседние категории с подсвеченной текущей; у корневой категории без детей соседи — все корневые. Категории, скрытые в меню, пропускаются. На главной, на странице товара и в листе без соседей секции не видно целиком, пустого отступа не остаётся; в превью конструктора такая секция тоже скрыта — выбирать её в списке секций.
- `menu` — пункты первого уровня меню магазина (`menu`, MenuId), любая страница. Пункт, адрес которого совпал с одной из хлебных крошек страницы (кроме главной), подсвечен. Вложенные пункты не выводятся. Без меню ряда нет.

**Вид.** `links` (по умолчанию): ссылки 15px medium вторичным цветом, высота пункта 48px; активный — основной цвет и черта 2px снизу; тонкая линия под рядом (`bottomBorder`, по умолчанию вкл.), над рядом — `topBorder`. `chips`: контурные кнопки высотой 40px, 14px medium, контур цветом границы темы, скругление по теме (skinRounded 100: от 0 у острой темы до 24px у самой мягкой); активная — инверсия палитры (фон цвета текста, текст цвета фона); шаг 8px, над и под рядом чипсов поля 12px.

**Десктоп (от 768px).** Ряд переносится на следующие строки, ничего не прячется; `align: center` центрирует. Шаг между ссылками 24px, на планшете 768–1023 и на телефоне — 20px.

**Телефон (до 767px, 390px).** Одна строка, листается пальцем, полоса прокрутки скрыта, правые 24px ряда растворяются маской, в конце ряда запас 24px, чтобы последний пункт выходил из-под маски. Ряд начинается слева, активный пункт стоит в нём первым, «Все» — сразу за ним (`view.activeFirstTouch`, по умолчанию включено), иначе на 390px активный уезжает за край. `view.showOn: touch` — ряд только на телефоне: на компьютере его повторяет меню шапки. Чипсы — 44px в высоту, ссылки — 48px: цели касания.

**Шапка категории** (`masthead`, только `current`, всё выключено по умолчанию). Порядок: крошки, обложка, название, ряд; между блоками 24px (на телефоне 16px), название и ряд ближе — 16px (12px). Крошки — только если нативный листинг заменён или его крошки выключены, иначе задвоятся. Обложка — картинка категории из кабинета: `slim` 5:1 и `banner` 7:2 на десктопе, 5:2 и 2:1 на телефоне, cover-кадрирование, скругление 200 по теме, alt — название категории; у категории без картинки блока нет. Название — заголовок секции 24px (ya-kit-section-title: h2; первый заголовок секции на странице витрина делает h1, и над нативным листингом это может быть он — по коду, живьём не проверено): у нативного листинга свой h1, включать только вместе с заменой листинга. На странице коллекции без категории — только крошки, обложка и название коллекции, ряда нет.

Отступы: поля секции single сверху и снизу, ритм 0 — как у листинга под рядом. Пока грузятся категории — скелетон высотой ряда (60% ширины). Одна секция на страницу, над листингом; фильтры листинга лучше в drawer: боковая панель inline уже выводит дерево категорий. Это не сетка категорий с картинками: плиток нет. Цвета — токены палитры, hex нет.

Не проверено живьём: совпадение адресов хлебных крошек с адресами меню (подсветка в `menu` может не сработать) и загрузка обложки через include-images.

**Переезд с v1.** На телефоне активный пункт встаёт первым в ряду (view.activeFirstTouch, по умолчанию включено — у перенесённой секции тоже); view.showOn touch прячет ряд от 768px.
