# custom-product-card — превью

Замена стандартной карточки товара (только страница товара, pdp): хлебные крошки, слева sticky медиагалерея, справа колонка — название, цены, выбор характеристик (цвет/размер), степпер количества, кнопка в корзину, аккордеоны с описанием и доставкой (город из location-controller). Все данные приходят из контроллеров товара — настроек почти нет (только палитра и отступы). Скелетоны на время загрузки.
