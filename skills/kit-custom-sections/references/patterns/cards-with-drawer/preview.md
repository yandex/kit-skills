# cards-with-drawer — превью

Сетка карточек, у каждой своя шторка с подробностями. Страница не перезагружается и не растягивается: подробный текст открывается поверх, а не раскрывается на месте, как у `faq-accordion`. Статичные плитки без подробностей — `advantages`; лицо карточки собрано на тех же токенах: подложка, поля, скругление, размеры шрифтов. Над сеткой необязательный заголовок секции (ya-kit-section-title: h2, первый заголовок секции на странице витрина делает h1).

**Карточка.** Нейтральная подложка темы (--ys-background-neutral), скругление из темы (skinRounded 150), поля 32px. Внутри столбиком: иконка 48×48 (необязательна), заголовок h3 18px semibold, короткий текст 16px основным цветом, внизу ссылка «Подробнее» 16px semibold со стрелкой. Ссылка прижата к низу карточки: в одном ряду ссылки стоят на одной линии, карточки ряда равной высоты. Нажимается вся карточка — зона нажатия кнопки растянута на неё, заголовок остаётся заголовком, а не текстом кнопки. Наведение (только на устройствах с hover) обводит карточку линией 1px вторичного цвета текста и сдвигает стрелку на 4px; фокус с клавиатуры — обводка 2px основным цветом текста. Карточка с `details: {}` (нет ни content, ни image) — статичная плитка без ссылки и без шторки.

**Десктоп.** columns карточек в ряд (2–4, по умолчанию 3), зазоры hGap/vGap (spacing-токены, по умолчанию 300 = 24px). До 1199px четыре колонки становятся тремя, до 1023px три и четыре — двумя.

**Телефон (до 767px, в том числе 390px).** columnsTouch карточек в ряд: 1 по умолчанию, 2 — только при коротких заголовках (на 390px карточка около 170px шириной). Зазоры не шире 12px между колонками и 16px между рядами, поля карточки 24px. При двух в ряд — компактная шкала: поля 16px, иконка 40px, заголовок 16px, текст и подпись ссылки 14px, стрелка 16px.

**Шторка от 768px (компьютер, планшет).** Платформа показывает окно по центру поверх затемнения: ширина до 640px (на узком окне — экран минус 48px), высота до экрана минус 96px, фон --ys-background-primary, скругление и тень платформы. Сверху прилипающая шапка: заголовок карточки h3 24px semibold и кнопка закрытия (крестик 24px, зона 40px). Ниже markdown-текст 16px с межстрочным 1.55, подзаголовки 18px, списки, ссылки цветом ссылок темы; под текстом картинка на всю ширину со скруглением темы. Текст можно выделить и скопировать (телефон, адрес). Закрывается крестиком, кликом по затемнению и Esc.

**Шторка до 767px (телефон).** Платформа показывает лист снизу во всю ширину с полоской-ручкой: закрывается свайпом вниз, тапом по затемнению и крестиком. Лист не выше экрана минус 64px — над ним всегда остаётся полоса затемнения, за которую видно страницу. Поля 16px, нижнее поле учитывает жестовую панель iOS; длинный текст прокручивается под прилипшей шапкой. В превью конструктора вид шторки берётся из устройства превью, а не из ширины окна.

**Цвета.** Все цвета — токены темы, hex-хардкода нет. Шторка рендерится порталом в конец страницы, вне секции: палитра секции (palette) на неё не действует, шторка в цветах основной темы витрины.

**Текст шторки.** Заголовок шторки — заголовок карточки: в markdown его не повторять. Подзаголовки внутри — `###`. Картинки внутри markdown и HTML платформа не выводит: картинка — только полем details.image. Ориентир — 300–1500 знаков.

**Доступность.** Кнопка озвучивается «Подробнее: <заголовок карточки>» и помечена как открывающая диалог; контент шторки — диалог с названием карточки. Иконка декоративная, без alt; у картинки шторки alt из imageAlt, пусто — заголовок карточки. Весь текст живой, в картинки не зашивается. Фокус в открытую шторку платформа не переносит: с клавиатуры шторка закрывается Esc.

**Ограничения.**
- Проверено офлайн (lint, new) и по исходникам платформы (drawer, clickable-area, markdown). Открытие и закрытие шторки, затемнение и вид на телефоне живьём не проверены: перед публикацией посмотреть превью конструктора на компьютере и телефоне.
- Стили шторки глобальные (G6 WARNING на каждое правило): классы с уникальным префиксом kcs-cwd-drawer, на другие блоки витрины не влияют.
- 3–12 карточек; больше — лучше разбить на две секции с заголовками.

**Переезд с v2.** Описания и лид — основным цветом текста (были вторичным, контраст 3,3–3,7:1); прежний приглушённый вид — descriptionTone: secondary. Новое необязательное поле cta {text, link, style button|link}: кнопка или ссылка под содержимым по линии заголовка — блок ведёт дальше, отдельная секция button-row под ним не нужна. Без ссылки или подписи не выводится; у перенесённой секции вид прежний.
