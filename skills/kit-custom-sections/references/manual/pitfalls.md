# Ловушки (каждый пункт — со статусом достоверности)

## Подтверждённые

- **`hPaddingTouch` в 10/10 официальных примеров** (2026-08-10): html читает `settings.section.hPaddingTouch`, схема объявляет `hPaddingMobile`. Отступ по краям на телефоне молча не работает у всех, кто копировал примеры. Патч каталога `fix-hpadding-touch` правит html; имя ТИПА `SectionHPaddingTouch` в схеме легитимно и остаётся.
- **`or` возвращает boolean** (2026-08-10, код хелпера): `{{or a "fallback"}}` напечатает `true`/`false`, не значение. Как текстовый fallback не годится.
- **`{{!-- --}}` печатается как текст** (2026-08-10): комментариев в DSL нет — удалять.
- **Два инстанса одного шаблона делят id и CSS-скоуп** (2026-08-10, код изолятора).
- **`json.Valid` — единственная серверная проверка** (2026-08-10, код бэка).
- **Таблицы атрибутов в доке неполны**: официальный пример FAQ использует `align` у `ya-kit-section-title`, отсутствующий в таблице. Поэтому неизвестный атрибут — warning, не error.
- **В таблицах доки типографские дефисы** (2026-08-10): 16 имён атрибутов записаны с U+2011 (`is‑disabled` и др.), копипаст из доки даёт неработающий атрибут; плюс две кириллические опечатки `is-сollapsable`, `on-сhange`.
- **Зелёный линт без проверки типов пропускал мёртвую секцию** (подтверждено 2026-08-10): объектный `$ref` в скалярной позиции (`titleText: ImageModel` в `text="{{…}}"`) валил секцию целиком — ноль DOM-элементов, ноль ошибок в консоли, CSS при этом впрыснут. Закрыто гейтом G16.
- **Официальный пример custom-snippets сам использует `:global(.drawer …)`**: контент `ya-kit-drawer` рендерится порталом вне скоупа секции — иначе его не стилизовать. Глобальные селекторы делят неймспейс всей витрины: префиксуйте классы контента drawer уникально.
- **`value` вместо `default` в схемах доки** (2026-08-10): примеры running-line и goods-cover содержат нестандартное ключевое слово `value` — форма его игнорирует; при импорте пропатчено на `default`.
- **Повторная привязка одного шаблона на одну страницу дублирует id** (подтверждено 2026-08-10): все инстансы получают одинаковый `id="ya-kit-<templateId>"` — невалидный HTML; стили работают, но ломается всё, что адресуется по id (якоря, getElementById). Для второго экземпляра лучше создать второй шаблон.
- **`//` в css секции отравляет каскад** (подтверждено 2026-08-10): CSSIsolator вырезает `//` до конца строки без учёта строк и url — `url(https://…)` одного `@font-face` оставил незакрытую скобку и обесцветил всю страницу. Никакой внешний ресурс из css секции недоступен: свой шрифт подключить нельзя (только шрифт темы), фоновые картинки — через `<img>`/атомы. Гейт G18.
- **`{{#each}}` без `as |m|` молча даёт пустые поля** (подтверждено 2026-08-10): линт был зелёный, DOM отрисовался без текста и src. Движку обязателен явный алиас — так пишут все doc-примеры. Гейт G17.
- **`--no-chrome` не защищает от подвала** (подтверждено 2026-08-10): сервер молча дописывает `YandexKit.Footer` на страницу, созданную без хрома (шапку — нет, асимметрия). Нативные Header/Footer из секции не перекрасить (портал вне скоупа, `:global(` под запретом), свои запрещены G12 — брендовый лендинг «под ключ» упирается в хром витрины.
- **Вывод `kit.py media upload` — не ImageModel** (подтверждено 2026-08-10): команда отдаёт `{id, public_path, …}`, а схема требует `{fileId, filePath}`. Маппинг: `fileId = id`, `filePath = public_path`; как есть вывод в answers не вставлять (теперь это ловит G8 по required тела ImageModel).

## Неподтверждённые (использовать нельзя, проверять живьём)

- Совет «задавайте `count` у `ya-kit-carousel`» из внутреннего промпта: код читается против него. До проверки прогоном паттерны с каруселью в каталог не берутся.
- «Пустая `json_schema = {}` — поддерживаемый сценарий»: код её пропускает, но «не падает» ≠ «поддерживается». Как продуктовое правило не используется.
