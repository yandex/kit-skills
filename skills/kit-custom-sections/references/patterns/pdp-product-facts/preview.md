# pdp-product-facts — превью

Блок под нативной карточкой товара (страница товара, pdp): выбранные характеристики открытого товара из каталога — аккордеоном, строками «подпись — значение» или в две колонки. Один инстанс на странице товара по умолчанию обслуживает все товары: товар берётся из `route.context.productCard.mainVariant`, контроллер не нужен. Нативная карточка (липкая кнопка покупки на телефоне, доставка, строки Сплита и Плюса, выбор вариантов) остаётся на месте. На других страницах, а также у товара, у которого нет ни одной из выбранных характеристик, блок исчезает целиком — без заголовка и без отступов (свёртка через `:has()`; в браузерах без `:has()` — Safari до 15.4, Firefox до 121 — останутся вертикальный отступ и, у товара без характеристик, заголовок секции).

**Десктоп.** Заголовок секции (h2, первый заголовок секции на странице витрина делает h1; необязателен). Аккордеон (по умолчанию): список шириной до 880px, пункты разделены тонкими линиями цвета границы темы; слева заголовок пункта h3 (lg, medium), справа шеврон 24px, который поворачивается при раскрытии (анимация — только если в системе не включено «уменьшить движение»); в теле значение 16px с интерлиньяжем 1.6 основным цветом, строка не длиннее 72 знаков, переносы строк из каталога сохраняются. Строки (`rows`): таблица до 880px — подпись 14px вторичным цветом (колонка 32%, не уже 8rem) и значение 16px основным цветом, тонкая линия над таблицей и под каждой строкой. Две колонки (`columns`): те же строки в две газетные колонки на всю ширину секции, промежуток 64px. `labelStyle`: `chip` — подпись инверсной плашкой (фон — основной цвет текста), `outline` — в контуре; только для строк и колонок. Вид значения `chips` — перечисление через запятую (или множественное значение) плашками 14px на нейтральном фоне со скруглением темы; в текстовом виде множественное значение без общей строки выводится через запятую. При `titleAlign: center` список центрируется под заголовком. Цвета — токены палитры, секция слушается тёмной палитры.

**Планшет (768–1023px).** Две колонки складываются в одну, остальное как на десктопе.

**Телефон (до 767px, рассчитано на ширину 390px).** Отступ по краям — `hPaddingMobile` (16px по умолчанию). Заголовки пунктов 16px, строка аккордеона не ниже 48px — удобно пальцем. В строках подпись по умолчанию встаёт над значением (`labelPositionTouch: above`), и длинное значение занимает всю ширину; `side` — подпись рядом, не шире 30% (не уже 6rem), только для коротких значений, а на экранах 360px и уже — тоже над значением. Многозначная характеристика печатается через запятую, как в нативном аккордеоне. Плашки переносятся по строкам. Горизонтальной прокрутки и фиксированных высот нет.

**Настройка.** Мерчант заводит характеристики в кабинете (или импортом) и заполняет их у товаров. В `modules` — название характеристики, как в каталоге (регистр и крайние пробелы не важны), при желании подпись `label` и вид `view`. Порядок пунктов — порядок `modules`; характеристика с пустым значением у товара не выводится. «Раскрыть первый пункт» раскрывает описание, если оно показано, иначе первый пункт `modules`; если у товара этой характеристики нет, всё свёрнуто.

**Описание и остальные характеристики.** Нативная карточка сама выводит описание и модуль «Характеристики». `showDescription` и `showOtherSpecs` включайте, когда соответствующий модуль в карточке выключен, иначе строки повторятся. Остальные характеристики — таблица всех прочих характеристик товара, кроме характеристик выбора варианта (цвет, размер) и уже выбранных в `modules`; исключение по `modules` — строгое совпадение названия, поэтому пишите его точно как в каталоге. В аккордеоне остальные характеристики — последний пункт, свёрнутый; в строках и колонках — отдельная таблица под подзаголовком.

**Ограничения.** Показывается вариант, открытый по ссылке: при переключении варианта в пределах одной карточки страница не перезагружается, и блок не обновляется (переход на другую карточку перезагружает страницу вместе с блоком) — различия между вариантами одной карточки держите в характеристиках выбора или в описании. Длинные тексты — в аккордеон, строки — для коротких значений. `ya-kit-product-detail-controller` в блоке намеренно не используется: второй экземпляр под нативной карточкой повторно отправляет в аналитику событие просмотра товара. Офлайн не проверено: рендер в превью конструктора (смотреть на странице товара — на других блок пуст), попадают ли в данные характеристики, скрытые в кабинете, и как множественное значение заполняет `values`.

**Переезд с v2.** Описания и лид — основным цветом текста (были вторичным, контраст 3,3–3,7:1); прежний приглушённый вид — descriptionTone: secondary. Выравнивание «как в теме» (titleAlign default) при центрированной теме центрирует и таблицу под заголовком, как явный центр. Многозначная характеристика печатается списком values через запятую, как в нативном аккордеоне, а не устаревшей строкой value через «; »; в чипсах value без values делится и по «;». На телефоне подпись строки по умолчанию над значением (labelPositionTouch above): прежде подпись занимала до 40% ширины, и длинное значение сжималось в 7 строк; прежний вид — side (подпись теперь не шире 30%).
