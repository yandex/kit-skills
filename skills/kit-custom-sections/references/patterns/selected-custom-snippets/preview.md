# selected-custom-snippets — превью

Сетка карточек избранных товаров пользователя (favourite-products-controller) со своим оформлением карточки и кнопкой-сердцем. Контроллер избранного читает только `as`: показывает все товары, которые покупатель отложил, — источника товаров и ограничения количества у него нет, атрибуты data-source и count доки убраны из разметки (drop-favourites-unread-attrs). Заголовок — настройка titleText (по умолчанию «Список желаний»). Фото карточки — первое фото товара, видео пропускается (first-photo-not-first-media); alt фото — название товара (add-selected-alt).

**Переезд с v3.** Настроек count и dataSource больше нет: контроллер избранного их не читал и всегда показывал все отложенные товары. Заголовок — настройка titleText (по умолчанию «Список желаний»); вид прежний.
