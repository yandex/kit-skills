# product-editorial — превью

Редакционный блок «товар + фото кампании»: одна живая карточка товара с кнопкой покупки рядом с одним-двумя фото мерчанта. Для запуска товара, новинки, товара недели, лимитированной серии. Это не полка: товар ровно один; полка из нескольких товаров — goods-snippets, текст с фото без покупки — text-media-split.

**Данные.** Показывается первый товар источника dataSource (featured-products-controller, count=1). Порядок товаров в категории может смениться, и в блоке молча окажется другой товар, поэтому лучше отдельная подборка из одного товара. Карточка — нативный сниппет товара по настройкам темы (фото в пропорциях темы, бейджи, название, цена, рейтинг и избранное — как включено в теме); смена фото при наведении выключена, встроенная кнопка сниппета выключена. Под сниппетом своя кнопка на всю ширину карточки: «В корзину» (buttonText; цвет — как у кнопок подборок товаров в теме: secondary или neutral, при остальных настройках primary), после добавления — степпер количества с потолком по остатку. Товар без остатка источник отдаёт, только если в магазине включён показ товаров не в наличии; тогда на фото сниппета платформа ставит плашку «Товар закончился», а вместо покупки кнопка «Сообщить о поступлении» (subscribeText) открывает платформенную подписку на поступление, как у нативного сниппета. Неактивная «Нет в наличии» (outOfStockText) — запасная ветка для товара без остатка при выключенном показе. При выключенном показе закончившийся товар из источника пропадает: с подборкой из одного товара секция скрывается целиком (и не оставляет пустой отступ ритма), с категорией его место занимает следующий товар. Пока товар грузится, на месте карточки нативный скелетон сниппета и неактивная кнопка той же высоты. В превью конструктора до выбора источника платформа подставляет товар-заглушку.

**Десктоп (от 1024px).** Заголовок (ya-kit-section-title, 24px; h2, первый заголовок секции на странице витрина делает h1), если задан. Под ним одна сетка в ряд, зазор 12px: карточка ¼ | второе фото imageSide ¼ | крупное фото imageMain ½ (в контейнере 1400px с полями 64px это около 312 + 312 + 624px). Высоту ряда задаёт карточка вместе с кнопкой (при фото товара 3:4 в теме около 540px, при 1:1 около 430px), оба фото растягиваются до неё с кадрированием cover, нижние края всех ячеек совпадают при любых пропорциях загруженных фото. Скругление фото — 150 по шкале скруглений темы, как у сниппета; в теме с острыми углами углы прямые. mediaLeft зеркалит ряд: крупное фото | второе фото | карточка. Если задано одно фото из двух: карточка ⅓, фото ⅔. Без фото остаётся одна карточка шириной до 22rem по центру; такой блок лучше заменить полкой goods-snippets. На ширине 1024px карточка около 218px — как карточка полки в четыре колонки. Фото не кликабельны: к товару ведёт карточка.

**Планшет (768–1023px).** Ряд становится горизонтальной лентой со snap-прокруткой, слайды по 44% ширины контента: карточка, крупное фото, второе фото; третий слайд выглядывает, полоса прокрутки скрыта. Лента стоит внутри боковых полей секции, слайды обрезаются по полю. С одним фото ленты нет: карточка 44%, фото занимает остаток ряда.

**Телефон (до 767px, на 390px).** Та же лента, слайды 85% ширины: при полях 16px контент 358px, карточка около 304px, зазор 8px, край следующего слайда (около 46px) выглядывает у правого поля секции, за ним 16px поля до края экрана. Порядок: карточка, крупное фото, второе фото; mediaLeft на телефоне не действует. Фото тянутся до высоты карточки (около 525px при фото товара 3:4), то есть становятся вертикальными кадрами. Без фото карточка на всю ширину.

**Фото.** Кадрирование cover по центру: главный объект держать в центре кадра. На десктопе крупное фото близко к квадрату, второе — вытянутое вертикальное (около 1:1,7); на телефоне оба вертикальные. Надписи в фото не зашивать: весь текст живой (заголовок, кнопки, название и цена из каталога). У каждого фото своё поле alt.

**Ограничения.** alt у фото (imageMainAlt, imageSideAlt), `is-loading` у сниппета и width="max" у кнопок и степпера движок принимает по коду, а в таблицах доки их нет; линт может дать G3 на атрибуты без пометки «(код)». Цвета только из палитры темы.

**Переезд с v1.** Разметка и стили прежние, изменилась схема. Ритм verticalRhythm/verticalRhythmTouch по умолчанию 0 (был 500/300): новая секция стоит на отступах секции, как нативные соседи; перенесённая сохраняет свои явные значения ритма.
