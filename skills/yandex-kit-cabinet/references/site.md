# Сайт и интеграции — блог, редиректы, вебхуки, гео

Endpoint map for site content and integrations. Auth, base URL, tool flags,
pagination and global conventions live in [`api.md`](api.md).
Mutating = POST/PUT/PATCH/DELETE (all need `--confirm`).

## Новости (блог)

| Метод  | Путь                  | Описание                                             |
| ------ | --------------------- | ---------------------------------------------------- |
| GET    | `/v1/blogs`           | Получение списка новостей (обязателен `-q status=…`) |
| POST   | `/v1/blogs`           | Создание новости                                     |
| GET    | `/v1/blogs/{blog_id}` | Получение новости по ID                              |
| PATCH  | `/v1/blogs/{blog_id}` | Обновление новости                                   |
| DELETE | `/v1/blogs/{blog_id}` | Удаление новости                                     |

## Редиректы

| Метод  | Путь                          | Описание                    |
| ------ | ----------------------------- | --------------------------- |
| GET    | `/v1/redirects`               | Получение списка редиректов |
| POST   | `/v1/redirects`               | Создание редиректа          |
| GET    | `/v1/redirects/{redirect_id}` | Получение редиректа по ID   |
| PATCH  | `/v1/redirects/{redirect_id}` | Обновление редиректа        |
| DELETE | `/v1/redirects/{redirect_id}` | Удаление редиректа          |

`url_from` уникален в пределах магазина: создание дубля вернёт конфликт.
Проверяйте существующие редиректы перед созданием.

## Вебхуки

| Метод  | Путь                                 | Описание                  |
| ------ | ------------------------------------ | ------------------------- |
| GET    | `/v1/webhooks`                       | Получение списка вебхуков |
| POST   | `/v1/webhooks`                       | Создание вебхука          |
| GET    | `/v1/webhooks/{webhook_id}`          | Получение вебхука по ID   |
| PATCH  | `/v1/webhooks/{webhook_id}`          | Обновление вебхука        |
| DELETE | `/v1/webhooks/{webhook_id}`          | Удаление вебхука          |
| POST   | `/v1/webhooks/{webhook_id}/validate` | Валидация вебхука         |

Типы событий (`events` в теле вебхука, enum `WebhookEventTypes`):

- `ORDER_STATUS_CHANGED` — изменился статус заказа;
- `ORDER_PAYMENT_STATUS_CHANGED` — изменился статус оплаты заказа;
- `ORDER_DELIVERY_STATUS_CHANGED` — изменился статус доставки заказа.

## Алерты

Системные уведомления магазина: что требует внимания владельца.

| Метод | Путь                            | Описание                                  |
| ----- | ------------------------------- | ----------------------------------------- |
| GET   | `/v1/alerts`                    | Список алертов (обязателен `-q status=…`) |
| POST  | `/v1/alerts/{alert_id}/resolve` | Пометить алерт решённым                   |

Сортировка: сначала критичные. `resolve` идемпотентен — повторный вызов для уже
закрытого алерта тоже вернёт `204`.
