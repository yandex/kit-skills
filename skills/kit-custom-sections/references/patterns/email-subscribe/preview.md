# email-subscribe — превью

**Когда брать.** Своя форма подписки нужна, если заголовок, текст и вид кнопки должны быть свои или кнопка должна стоять внутри поля. Обычную подписку ставит нативный виджет подписки через kit-storefront-constructor: у него есть экран «уже подписаны», а текст о скидке он строит из промокода сам. Не ставить на страницу, где уже стоит нативная подписка: она общая для страницы, и покупатель увидит две формы.

**Десктоп (от 1024px).** На подложке (`surface: panel`) блок лежит на вторичном фоне палитры, углы скруглены по теме, внутренние поля 56px сверху и снизу, 64px по бокам. `layout: center` — одна колонка до 36rem по центру, текст по центру. `left` — та же колонка у левого края. `two-columns` — две равные колонки с промежутком 80px: слева заголовок и текст, справа форма, по вертикали по центру. Заголовок — h2 размера заголовка темы bold, текст — md основным цветом, переносы строк из поля сохраняются. Форма `row`: поле растягивается, кнопка справа той же высоты (`form.controlSize`, по умолчанию lg), промежуток 12px. `inline-pill`: рамка вокруг поля и кнопки, фон основного цвета палитры, кнопка внутри рамки с отступом 4px; при фокусе рамка темнеет, при ошибке становится цвета ошибки. `stacked`: кнопка под полем на всю ширину. Под формой согласие: галочка (не отмечена) и текст markdown sm вторичным цветом со ссылкой на `/privacy`.

**Планшет (768–1023px).** Поля подложки 48px. `two-columns` складывается в одну колонку до 40rem, как `left`.

**Телефон (до 767px, проверять на 390px).** Поля подложки 32px сверху и снизу, 24px по бокам. Поле и кнопка всегда друг под другом на всю ширину. У `inline-pill` рамка остаётся и охватывает поле и кнопку под ним. Промежутки 24px.

**Промокод.** Если выбран `promo`, заголовок — `headlineWithPromo` плюс размер скидки цветом скидки из темы: процент как «10%», фиксированная сумма в рублях. Под заголовком появляются подписи-«таблетки», только если так настроен промокод: `terms.firstOrder` для скидки на первый заказ и `terms.minOrder` с суммой для минимального заказа. Пока промокод загружается, на месте заголовка серая полоса высотой 30px и шириной до 280px, поэтому заголовок не прыгает. Без промокода заголовок — `headline`, и о скидке секция не пишет.

**После подписки** форма заменяется блоком: круг 56px (на телефоне 48px) цвета бренда с галочкой, заголовок `success.title` и текст. Текст `success.textWithPromo` показывается только при выбранном промокоде.

**Ограничения.** Отправка только кнопкой: Enter в поле форму не отправляет. Экрана «уже подписаны» нет: ответ сервера («почта уже подписана», сбой) выводится текстом ошибки под полем. С `consent.mode: checkbox` подписка не уходит без галочки, под ней появляется текст ошибки. Отмеченной заранее галочки нет. Текст согласия не должен называть кнопку. Весь текст — живой, цвета — токены темы.

**Переезд с v1.** Заголовок секции теперь h2, вровень с заголовками нативных секций (был h3); вид не меняется. Описания и лид — основным цветом текста (были вторичным, контраст 3,3–3,7:1); прежний приглушённый вид — descriptionTone: secondary.
