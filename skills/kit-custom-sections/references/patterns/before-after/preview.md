# before-after — превью

Заголовок секции, под ним квадратный (1:1) блок сравнения: два изображения друг над другом, правое обрезается clip-path по позиции перетаскиваемого ползунка (drag-controller, ось X). Ползунок — скруглённая капсула с тремя вертикальными штрихами по центру границы. Картинки «до» и «после» передаются в answers объектами из kit.py media upload (before.image / after.image) или задаются мерчантом в форме. Во всю ширину блок 1:1 очень высок — сузить можно только section.hPaddingDesktop (максимум enum 1600 = 176px с каждой стороны). Токены темы, без хардкода.
