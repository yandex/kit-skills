# static-reviews — превью

Заголовок, под ним карусель карточек отзывов (3 колонки на десктопе, 1 на мобильной). Карточка: строка рейтинга, заголовок отзыва (semibold), текст, ниже автор и серая подпись (дата/город). Отзывы статические — задаются мерчантом, не из внешней системы. Токены темы.

**Переезд с v2.** Новое необязательное поле cta {text, link, style button|link}: кнопка или ссылка под содержимым по линии заголовка — блок ведёт дальше, отдельная секция button-row под ним не нужна. Без ссылки или подписи не выводится; у перенесённой секции вид прежний.
