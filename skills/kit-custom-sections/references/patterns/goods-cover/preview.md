# goods-cover — превью

Двухколоночный блок: слева текстовая обложка — крупный брендовый заголовок (3xl bold), markdown-описание и кнопка «Перейти» (если задана ссылка), справа карусель товаров (3 колонки, 1 на мобильной) из featured-products-controller. Источник товаров и ссылку мерчант выбирает в форме. Схема пропатчена: value -> default у cover.title.
